# Material Walk — Field Kit Godot demo

Open `project.godot` in **Godot 4.7.2**, let its first import finish, then press **F5**. The demo runs locally with no plugins or network access. Godot is a separate developer tool and is not included in Field Kit's installer or this project.

Walk with **WASD / arrow keys**, jump with **Space**, and hold the **right mouse button** while dragging to orbit. Collect the three gold markers. **Reset walk** restores the player and markers. Change the texture picker to see the same exported PNG repeat across the floor, cube and sphere. Pick a sound and click **Play loop** to audition the exported WAV; playback begins paused and at a quiet level.

The supplied pack under `assets/field-kit/` is explicitly **synthetic test content**, generated by Field Kit's deterministic image/audio fixtures and exported through the real application. It is not photography or a real field recording. Its manifest contains sample credits entered by the test. No sample library is loaded into Field Kit automatically, and no application or asset license is assigned here.

To try your own materials, export a **New asset folder** from Field Kit. Make a separate copy of this demo, replace only its sample `assets/field-kit/` contents with that completed pack, and reopen the project. Include at least one texture and one sound for both pickers. The game reads the manifest, uses Godot's imported resources, enables texture repeat, and loops the entire already-processed WAV. It does not apply another audio crossfade or generate PBR channels.

This project's WAV import defaults use **PCM (Uncompressed)** and leave normalization, trimming, rate conversion and mono conversion off. Godot's normal default is QOA compression, which changes the decoded audio; if you import into another project, choose PCM and reimport when you want to preserve Field Kit's processed samples. See [Godot's WAV importer documentation](https://docs.godotengine.org/en/stable/classes/class_resourceimporterwav.html).

`verify.gd` is a developer-only check invoked with `--verify`; normal F5 play does not run it. The verification script checks real imported dimensions, PCM format, duration, decoded pixels, material changes, walking, jumping, orbiting, collectible triggers, reset and loop playback. A captured runtime frame is separate evidence from headless import. See the release verification receipt for the engine/version and checks actually run. Physical-speaker listening and other engines are not claimed.
